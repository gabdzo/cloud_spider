# UX review, 2026-10-12 (both themes)

Gabriel: "Sometimes I find it too cluttered but in a way I like it. However
sometimes it's hard to orient, like u dont know whats clickable and what not."
Goal: keep the dense Pip-Boy character, fix orientation.

Audit: every main view (MAP, SNIFF, CLUSTER › TOPOLOGY / SERVICES / LOG
ERRORS, K9S, VAULTS, STACKS, LEARN, SCORE, ASK) in Pip and PRO, SAMPLE data,
1600×1000. Screenshots: `/workspace/demo-shots/ux/before/*.png`, after the
fixes `/workspace/demo-shots/ux/after/*.png`; `probe.json` in each counts
clickable elements without a pointer cursor and tab stops without a ring.

## Findings

1. **Unlit tabs look disabled (Pip).** The top tabs and the console key
   labels (STACKS, LEARN, SCORE, ASK) are `--pip-dim` on near-black (3.5:1,
   the console plates ~2.5:1): they read as greyed out, not as "click me".
2. **Dim text is below 4.5:1 everywhere.** Meta lines, stats, legends, column
   heads use `--pip-dim` (#0a7a34 on #04140a = 3.5:1; PRO #6b737d = 3.7:1).
   The hierarchy primary / secondary / info collapses into "bright" vs
   "hard to read".
3. **No "where am I".** SCORE, STACKS and LEARN open as pages but the lit top
   tab stays VAULTS (or MAP); CLUSTER has a second tab row that looks like the
   filter buttons below it; K9S overlays whatever was open. Nothing says
   CLUSTER › SERVICES.
4. **Clickable vs info is not consistent.** Selects (Group by, K9S ns, Score
   target), the LB select and some chips had no pointer cursor; legend chips
   (PUBLIC / PRIVATE / TARGET on the map, badge keys) are styled like buttons
   but are not clickable; links that leave the view (DEBUG FROM INSIDE) look
   like plain text.
5. **Disabled has no single look.** Some disabled buttons only lose their
   glow; nothing shows `not-allowed`.
6. **Focus rings only on the header.** `.tab`, `.key`, `.switch` have a dashed
   ring; panel buttons (graph, K9S, LOG ERRORS, Score) rely on the browser
   default, invisible on dark green; one early tab stop has no ring at all.
7. **Abbreviations.** SVC/WL/HOOK/… are explained in SERVICES (legend + badge
   key, #284); the map's IGW, NAT, AZ, CAPS, LIT and the footer counters
   (PARTS, HANGING) still need tooltips.
8. **Spacing.** Prompt line, morning report, sub-tabs and the screen header
   stack with 0–4 px between them; the eye has no anchor where a view starts.

## Fixed in this pass

- PR ux-affordances: one affordance language (pointer on every clickable incl.
  selects, hover lift on panel buttons, `not-allowed` + fade for disabled, a
  dashed Pip / solid PRO focus ring on every focusable), dim TEXT lifted to
  ≥ 4.5:1 through `--pip-dim-text` (borders and canvas keep the dark ramp),
  unlit tab and console labels brighter, underlined links that leave the view,
  and **YOU ARE IN CLUSTER › SERVICES** above the screen, read from the lit
  buttons so it cannot drift (src/where.js).

- PR ux-pass2 (before/after in `/workspace/demo-shots/ux/after2/`):
  - Legend chips are a KEY: the map legend is one flat strip with "KEY" in
    front instead of a box per item (Pip map golden hashes regenerated on
    purpose); SERVICES legend and badge key lose any bevel, get "KEY" and a
    help cursor (4).
  - Tooltips: every footer counter (VPC, SUBNETS, SHACKS, LIT, PARTS, BROKEN,
    HANGING, HEALTHY) and CAPS; map hover text spells out IGW, NAT, AZ, EKS,
    ALB, NLB, ENI, CIDR, EC2, CDN, RDS (7).
  - One 8 px step between breadcrumb, prompt, morning report, sub-tabs and
    the screen header (8).
  - SCORE, LEARN and STACKS cover the screen, so the view tab under them
    goes dark and only their key is lit; YOU ARE IN says SCORE (3).
  - YOU ARE IN sits on a dark plate above the glass, bright place names.
