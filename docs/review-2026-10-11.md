# Cloud Spider UX / QA review, 2026-10-11 (overnight)

Scope: every view on main (up to #48) at 760, 1280 and 1920, in sample and fake-live, plus read-only checks against Gabriel's running app. Method: gstack design-review (first impression, trunk test, 10-category checklist, goodwill, A–F), qa (severity × category taxonomy) and devex-review (TTHW and 8 steps), run headless. Interactive steps were skipped and the recommended option taken each time.

Screenshots are on the `spider-shots` branch under `review/`. Fixes shipped as small PRs (§4). Bigger or debatable items are recommendations (§5).

> **Important testing note: fonts.** Gabriel's Mac has neither Share Tech Mono nor VT323, so the page falls back to **Menlo** (about 8.4 px per character at 14 px). The box has VT323 (about 5.6 px), so every box screenshot until now showed a narrower UI than the one Gabriel sees. The canvas layout (`CHAR_W = 8.5` in layout.js / arch-layout.js) is sized for Menlo, but the HTML header was not. All shots in this review use a fontconfig that hides VT323 and Share Tech Mono, which reproduces the Mac widths exactly (plate 301, tabs 526, console 415 px). Other agents taking screenshots should do the same, or the header and LCD truncations stay invisible to them. Recipe: `FONTCONFIG_FILE` with `<rejectfont><glob>*VT323*</glob><glob>*ShareTech*</glob></rejectfont>`.

## 1. Why the EKS demo was not on the map (root cause)

- Before #42 the main map read only AWS APIs (EC2, ELB, EKS DescribeCluster/Nodegroup). It drew the cluster as a card and its one node as a house. The workloads (api, web, loadgen, otel-collector in `demo`) were read only by the CLUSTER tab, through the read-only kube context `/api/cluster`. So no pods or apps ever reached the map, by design.
- #42 (merged overnight) adds the EKS compound to the map: nodes, apps and pods, with 1/2/3/AUTO detail. It shares the Cluster read.
- Gabriel's server was restarted at about 02:20 on `731865c` (his local commit on top of #43). His live map now shows **cloudspider-up · 1 node · 9 apps · 11 pods**: [live-map-bottom-1280](https://raw.githubusercontent.com/gabdzo/cloud_spider/spider-shots/review/live/live-map-bottom-1280.png). Before #42 it did not: [live-before-map-1280](https://raw.githubusercontent.com/gabdzo/cloud_spider/spider-shots/review/live/live-before-map-1280.png).
- What is left: at 1280 the compound sits **below the fold**, under the empty default-VPC strip and the public subnet header, so you have to scroll to find it ([live-map-1280](https://raw.githubusercontent.com/gabdzo/cloud_spider/spider-shots/review/live/live-map-1280.png)). See R2.
- Live telemetry still says `otel-metrics: forbidden for the viewer role`. RUN-ME §14 (`pulumi up -s demo`, which adds the services/proxy rule) has not been run. Path shows "eu-north-1 has no load balancers" because the EKS demo has no load balancer. That is now explained on screen (#45).

## 5. Recommendations (not done: bigger or debatable)

- **R1 – Ship the font.** Vendor Share Tech Mono (OFL) as a woff2 with `@font-face`, so the Mac, the box and screenshots all render the intended face. This changes the look on Gabriel's Mac, so it is his call. Until then, keep testing with the Menlo-metric fontconfig.
- **R2 – Use the width.** Flow VPCs side by side when the viewport allows (ROW_LIMIT tied to the viewport), and order the region so the VPC with the EKS compound comes before an empty default VPC. On Gabriel's account the compound would then be above the fold at 1280.
- **R3 – Narrow screens.** Auto-fold the morning report under about 900 px, or let the over-map panels (LEARN, STACKS, ASK) cover it. Consider a compact header at 760: plate without the subtitle, and tabs as icon plus short label.
- **R4 – URL state.** Hash routes `#path?lb=…`, `#cluster`, `#learn/<lab>`, `#stacks/<card>`, like `#vaults`. Then reload, and the after-pull routine, keep your place.
- **R5 – Keyboard map.** Arrow keys or Tab cycling through map entities (the hit list already exists), with Enter to open the plate. Make radio rows and morning cards buttons.
- **R6 – CAPS copy and placement.** Fix the `costFailure` sentence (finding 15). At ≥1600, put CAPS on the top row and drop the near-empty gauges row.
- **R7 – RUN-ME pass.** Once Gabriel's local RUN-ME edits are committed: button names (run / take it down / preview), `CLOUDSPIDER_LOG_GROUP` and `PORT` in §2, and mark §1 as done.
- **R8 – Telemetry.** Run RUN-ME §14 (`pulumi up -s demo`) so OTEL metrics stop being "forbidden for the viewer role". This is an AWS and cluster write, so it is Gabriel's step.
